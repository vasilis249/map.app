# Δοκιμή σε 2 πραγματικά iPhone — Push-to-talk (Φάση 3)

Ό,τι δεν μπορεί να ελεγχθεί στον browser του container: το πραγματικό Supabase Realtime (binary κομμάτια ήχου,
presence, private channels), το iOS audio session (silent switch, κλειδωμένη οθόνη), η τοποθεσία στο παρασκήνιο.

## 0. Τι χρειάζομαι από σένα (μία φορά)
1. **Supabase project** (καινούργιο). Δώσε μου στο chat το Project URL και το **publishable/anon key**.
   Το service-role key ΜΗΝ το στείλεις, δεν χρειάζεται. Τα keys μπαίνουν μόνο σε τοπικό `.env`, όχι στο repo.
   Μετά τη δοκιμή, κάνε rotate όσα στείλεις στο chat.
2. **Cloudflare account** (δωρεάν), για το hosting του web app (`npm run deploy`, με `wrangler login` από
   τον υπολογιστή σου). Εναλλακτικά, για τη δοκιμή, τρέχουμε τοπικά στο LAN σου (`CAP_SERVER_URL=http://<ip>:3000`).
3. **Mac με Xcode** + Apple Developer account (Team) και 2 iPhone (iOS 16.4+), συνδεδεμένα με καλώδιο ή Wi-Fi.

## 1. Στήσιμο (το κάνω εγώ με όσα μου δώσεις, εσύ τρέχεις τις εντολές στο Mac)
- Supabase → SQL editor: εκτέλεσε `supabase/migrations/20261011100000_baseline.sql`.
- Supabase → Database → Extensions: ενεργό το `pg_cron` (για τις λήξεις). Αν το ενεργοποιήσεις μετά το migration,
  ξανατρέξε μόνο το τελευταίο μπλοκ `DO $cron$ … $cron$`.
- Supabase → Realtime → Settings: **Allow public access = off** (μόνο private channels, με τα policies μας).
- Supabase → Authentication → URL configuration: πρόσθεσε `mapapp://app/login` και το URL του web app.
- `.env` στο Mac (δες `.env.example`): VITE_SUPABASE_URL, VITE_SUPABASE_PUBLISHABLE_KEY, CAP_SERVER_URL, CAP_APP_ID.
- `npm ci && npm run deploy` (ή `npm run dev -- --host` για LAN), μετά `npm run ios:sync && npm run ios:open`.
- Xcode → App target → Signing & Capabilities: το Team σου. Τα Background Modes (Audio, Location) είναι ήδη στο Info.plist.
- Run σε κάθε iPhone. Φτιάξε 2 λογαριασμούς (A, B, και οι δύο 18+) και κάντε **follow ο ένας τον άλλο** (= φίλοι).

## 3. Τι μου στέλνεις μετά
- Τον πίνακα με ✅/❌ και, για κάθε ❌, τι έγινε (screenshot ή περιγραφή).
- Από το Supabase SQL editor (μόνο τεχνικοί μετρητές, ποτέ ήχος):
  `select at, user_id, data from private.walkie_diag order by id desc limit 50;`
- Μοντέλα iPhone και εκδόσεις iOS.

Προαιρετικά, πριν από τα iPhone: το `docs/kit/rt-probe/` είναι ένας προσωρινός Cloudflare Worker που ελέγχει την
πραγματική διαδρομή Realtime (binary + presence) με 2 δοκιμαστικούς χρήστες. Το deploy-άρουμε, τον ελέγχουμε, και
μετά τον σβήνουμε μαζί με τους χρήστες.
