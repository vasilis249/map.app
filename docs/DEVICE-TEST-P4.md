# Δοκιμή σε πραγματικό iPhone — Πλοήγηση (Φάση 4)

Ό,τι δεν ελέγχεται στον browser του container: η πραγματική υπηρεσία διαδρομών (Stadia Maps), η ελληνική φωνή του
iPhone, η πλοήγηση με κλειδωμένη οθόνη / στο background, φωνή + walkie μαζί, πραγματική οδήγηση (ταχύτητα, πορεία).

## 0. Τι χρειάζομαι από σένα (μία φορά, μαζί με όσα λέει το DEVICE-TEST-P3.md)
1. **Λογαριασμός Stadia Maps** (stadiamaps.com) → Create API key. Για εμπορική χρήση χρειάζεται πληρωμένο πλάνο
   (Starter). Το κλειδί **δεν** μπαίνει στο `.env` ούτε στο repo· μπαίνει μόνο ως secret του Worker:
   `npx wrangler secret put ROUTING_API_KEY` (από τον υπολογιστή σου, μετά το `wrangler login`).
   Αν μου το στείλεις στο chat, κάνε rotate μετά τη δοκιμή.
2. Ο Worker χρειάζεται και `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY` (ως vars/secrets): μ' αυτά ελέγχει τη σύνδεση
   και τα όρια (RPC `nav_quota`) πριν καλέσει τη Stadia.
3. Νέο build στο Xcode (`npm run ios:sync` → Xcode → Run): η Φάση 4 πρόσθεσε 2 native plugins (φωνή, οθόνη ανοιχτή).
   Ένα παλιό build δουλεύει, αλλά με τη φωνή του web view και χωρίς πλοήγηση με κλειδωμένη οθόνη.

## 1. Σενάρια (σημείωσε ✅ / ❌ και ό,τι παράξενο)
| # | Τι κάνεις | Τι πρέπει να γίνει |
|---|---|---|
| 1 | Χάρτης → «Πού πας;» → γράψε μια διεύθυνση | Προτάσεις όσο γράφεις, οι κοντινές πρώτες |
| 2 | Διάλεξε μία | Έως 3 διαδρομές με χρόνο, απόσταση, «μέσω …»· η ταχύτερη σημειωμένη· πάτημα σε γκρι γραμμή = επιλογή |
| 3 | «Έναρξη» | Κάμερα με κλίση, η πορεία προς τα πάνω· banner με στροφή + απόσταση· φωνή: «Οδηγήστε …» |
| 4 | Οδήγησε (συνοδηγός κρατά το κινητό) | «Σε 400 μέτρα, …» και λίγο πριν τη στροφή η οδηγία· σωστή ώρα άφιξης |
| 5 | **Silent switch** ON | Η φωνή ακούγεται; (σημείωσε — εξαρτάται από το iOS) |
| 6 | Κλείδωσε την οθόνη για 2–3 στροφές | Οι οδηγίες συνεχίζουν· μπλε ένδειξη τοποθεσίας πάνω αριστερά |
| 7 | Μουσική από Spotify και πλοήγηση | Η μουσική χαμηλώνει όσο μιλά η οδηγία; (σημείωσε) |
| 8 | Φίλος σου μιλά στο walkie (ανοιχτό κανάλι) ακριβώς πριν από στροφή | Η οδηγία περιμένει και λέγεται μετά· καμία οδηγία δεν χάνεται σιωπηλά |
| 9 | Εσύ πατάς push-to-talk σε κάποιον κοντά σου ενώ μιλά η οδηγία | Η οδηγία σταματά και ξαναλέγεται μόλις αφήσεις· ο άλλος δεν ακούει τη φωνή της πλοήγησης |
| 10 | Βγες από τη διαδρομή (λάθος στροφή) | Σε ~5 s «Εκτός διαδρομής» → «Νέα διαδρομή.» και νέα γραμμή |
| 11 | Φτάσε | «Ο προορισμός σας …», banner «Έφτασες»· «Τέλος» → κανονικός χάρτης |
| 12 | Πλοήγηση 30 λεπτά | Μπαταρία (% πριν/μετά), ζέσταμα, η οθόνη δεν σβήνει |
| 13 | Ενώ κινείσαι > 18 km/h, «Πού πας;» | Η αναζήτηση είναι κλειδωμένη («Σταμάτα με ασφάλεια πρώτα») |
| 14 | Κουμπί φωνής (ηχείο) κατά την πλοήγηση | Σίγαση / φωνή ξανά· θυμάται την επιλογή |
| 15 | Οδήγηση σε πόλη και σε λεωφόρο | Το βελάκι κυλά ομαλά (όχι «πηδηματάκια» κάθε δευτερόλεπτο), η κάμερα στρίβει απαλά πριν τη γωνία, ανοίγει (zoom out) στη λεωφόρο |
| 16 | Ταχύμετρο | Δείχνει την ταχύτητα (σύγκρινε με το κοντέρ)· 0 στο φανάρι |
| 17 | Σταμάτα σε φανάρι 3–4 s | Κοντινό, πιο κεκλιμένο 3D· κοντινοί χρήστες ως 3D αυτοκίνητα / πεζοί με τη φωτογραφία τους από πάνω |
| 18 | Ξεκίνα πάλι | Η κάμερα ανοίγει ομαλά, χωρίς τινάγματα |
