## Stack and architecture
- **Web app**: TanStack Start (React 19, Vite 8, file routes in `src/routes`), Tailwind 4 + `src/design-system.css`
  (tokens), TanStack Query, i18next (`src/i18n/el.ts` default, `en.ts`). Client-rendered (`src/start.ts`
  `defaultSsr: false`): the session is in localStorage and map/audio/location exist only in the browser. The Worker
  (`src/server.ts`, wrangler `main`) serves the HTML shell and adds security headers (`src/lib/security-headers.server.ts`).
- **Hosting**: Cloudflare Workers via `@cloudflare/vite-plugin` (wrangler.jsonc). Server-side vars: SUPABASE_URL,
  SUPABASE_PUBLISHABLE_KEY (+ ROUTING_API_KEY in P4) as Worker vars/secrets. Client build vars: VITE_SUPABASE_URL,
  VITE_SUPABASE_PUBLISHABLE_KEY (.env, see .env.example).
- **Backend**: Supabase. One baseline migration `supabase/migrations/20261011100000_baseline.sql`. RLS on every
  table; clients only SELECT (+ column UPDATE on own profile / notification read_at); every write is a SECURITY
  DEFINER RPC in `public` with `SET search_path = ''` that starts with `private.me()` (signed in, not disabled).
  Helpers in `private` (EXECUTE revoked; only `is_blocked`, `walkie_topic_ok`, `nearby_topic_ok` granted because
  RLS policies call them). Rate limits: `private.rate_limit(action, max, window)`.
- **Native**: Capacitor 8 iOS shell (SPM) loading the hosted URL (`capacitor.config.ts`, `CAP_SERVER_URL`),
  `ios/` generated by `cap add ios`; `scripts/patch-native-plugins.mjs` lifts background-geolocation to
  capacitor-swift-pm 8 and adds the iOS 14 temporary-full-accuracy request (purpose key `PreciseMap`).
- **Map**: MapLibre GL 6.11.2 (pinned, kit) + OpenFreeMap liberty/dark (no key). Worker bundled via
  `?worker&url` + `worker.format: "es"` (LESSONS #19).

### Data model (baseline)
profiles (username, full_name, bio, avatar_path, disabled) · follows (asymmetric; mutual = friends) · blocks (trigger
`private.on_block` wipes follows, notifications, walkie + nearby messages/knocks of the pair) · private.admins ·
notifications (follow | nearby | walkie; one row per actor+kind, moved to top) · reports (user | walkie | nearby) ·
location_sharing (off | friends | everyone; talk_from everyone | following | nobody) · private.user_locations (latest
only) · private.nearby_knocks / nearby_messages (+ private.nearby_audio, 24 h) · walkie_messages (+ private.walkie_audio,
24 h) · walkie_contacts (channel on ≤ 10, seen_at) · private.walkie_diag · private.rate_events · storage bucket `avatars`.
Realtime: private channels `walkie:<a>:<b>`, `nearby:<a>:<b>` (a < b) and inbox `nearby-in:<uid>` (read-only,
written by `realtime.send` from `nearby_knock`), authorized by policies on `realtime.messages`.

### Location rules (server-enforced)
- Near = `private.near_m()` = **200 m** (client mirror `src/lib/location/near.ts`), from the caller's STORED position.
- Reciprocity: `map_people` returns nothing unless you share and have a position (≤ 15 min for strangers, ≤ 1 h for
  friends' last-known). Strangers need fresh (≤ 15 min) positions on both sides.
- Writes: `update_my_location` stores at most 1 per second (driving needs 1–2 s), drops nonsense accuracy/heading/speed,
  refuses out-of-range coordinates; ignored while sharing is off. Turning sharing off deletes the position.
- Expiry: pg_cron `expire-locations` every 10 min deletes positions older than 1 h (+ nearby 24 h, walkie 24 h, misc).

## Decisions
- D1 (P0) Plain `vite.config.ts` with `@cloudflare/vite-plugin` + `tanstackStart()` instead of the kit's
  `@lovable.dev/vite-tanstack-config` wrapper (fewer hidden plugins; same result).
- D2 (P0) Client-rendered app (`defaultSsr: false`); security headers from `src/server.ts`.
- D3 (P0) Radius 200 m everywhere (kit: 500 m); map radius chips 50 / 100 / 200 m.
- D4 (P0/P1) Position write floor 0.9 s on the server (kit: 3 s). Tracker (owner-approved change): minimum gap 1 s
  above 5 m/s (18 km/h), else the kit's 3 s; all other kit send rules unchanged.
- D5 (P0) Notifications: follow / nearby (= someone talked to you on the map; covers "knocks") / walkie (missed).
- D6 (P0) No catch-all Realtime policy (Speak had one); only walkie / nearby / inbox topics are allowed.
- D7 (P0) `img-src` no longer allows any https host (Speak's news covers); avatars come from Supabase only.
- D8 (owner OK before P1, my recommendations): iOS only for now; Apple Developer Program now; routing + geocoding =
  Stadia Maps (hosted Valhalla + Pelias autocomplete; Starter plan for commercial use) behind one swappable module
  (P4); friends see each other at any distance ("friends" mode); 18+ only; driving profile first.
- D9 (P1) 18+ = a declaration: sign-up checkbox (user metadata `age_confirmed: true` → profiles.age_confirmed_at) or
  `confirm_age()` for accounts created without it; `private.me()` raises `age_not_confirmed` until then and the app
  shows the age gate (`src/components/age-gate.tsx`). App Store age rating to match (P6).
- D10 (P1) Ghost mode = sharing `off` with one tap on the map (server deletes the position at once); the previous
  mode is remembered on the device so one more tap restores it (`src/components/location/ghost-button.tsx`).
- D11 Until the first deploy to a real Supabase project the baseline migration is amended in place; after it, only
  new migrations.
- D12 (P2) Moderation: admins (`private.admins`, granted by SQL) work a queue (`admin_reports`), can hear a reported
  transmission while it is kept (24 h), dismiss, or disable an account (closes all its open reports; position and
  open channels to them deleted). Every decision records resolved_by / resolved_at / resolution. A disabled account
  sees a suspension screen; others can't find it anywhere. Re-enable from the resolved tab.
- D13 (P2) Lists page with offset (50 per page, "More"); notices carry "Follow back"; suggestions on empty search.
- D14 (P3) Talk safety: a one-time notice before the first push-to-talk (`SafetyGate`, remembered on the device);
  while the phone moves faster than 18 km/h (`useDriving`, from the device's own fixes) the talk screens show only the
  name and the big button (no history, no switches). Map card PTT enlarged to 144 px; the card scrolls inside
  (max 92 dvh) and the PTT is `data-vaul-no-drag` (holding it must never drag the bottom sheet).
- D15 (P3) Report one saved transmission (flag on the other person's history rows) → `report_content('walkie'|'nearby')`.
  The Walkie tab shows the unheard count. The map's bottom controls pass taps through their empty space (markers
  underneath stay tappable).
- PROPOSAL (needs owner OK, tracker.ts): when a fix is skipped only because of the 3 s gate, send it when the gate
  opens (trailing send). Today a fix skipped right before you stop waits for the 60 s heartbeat.
- PENDING: app name + bundle id (placeholders: `MapApp`, `gr.innera.mapapp`, scheme `mapapp` in `src/lib/brand.ts`,
  `capacitor.config.ts`, `ios/App/App/Info.plist`).
